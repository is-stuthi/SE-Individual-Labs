## Project Overview

A multi-currency expense-sharing utility that records uneven group expenses, converts foreign currencies using daily exchange rates, and computes a minimum-transaction debt settlement graph.

**Actors:** Group Traveler, Trip Admin (external systems: Exchange Rate Service, Payment Gateway)
